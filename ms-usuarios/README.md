# Microservicio ms-usuarios

Este microservicio gestiona la persistencia de usuarios y sirve como punto de validación sincrónica para el proceso de compras.

## Requisitos Previos
- Java 17
- Apache Maven 3.x
- MySQL activo vía XAMPP

## Configuración de Base de Datos
1. Iniciar XAMPP y activar los servicios de **Apache** y **MySQL**.
2. Crear la base de datos relacional llamada `bd_usuarios` en phpMyAdmin (`http://localhost/phpmyadmin`).
